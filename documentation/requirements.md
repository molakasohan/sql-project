# Requirements – Food Ordering System

## Project Idea
A small database for an online food ordering app. Customers order food items from a menu.

## What the database must do
1. Store customer details
2. Store menu items with price and stock
3. Store orders placed by customers
4. Store which items (and how many) are in each order
5. Calculate the total amount of an order
6. Reduce stock automatically when an item is ordered
7. Give simple reports (best selling items, revenue, orders per customer)

## Tools
MySQL 8.0 + MySQL Workbench
